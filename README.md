# Hanout Credit — MVP

دفتر كريدي رقمي للحانوت، مصمم للتليفون وبواجهة عربية RTL.

## الخصائص الحالية
- إضافة وتعديل وحذف الزبناء.
- تسجيل الكريدي والأداء الجزئي أو الكامل.
- حساب الرصيد من سجل العمليات، ماشي بتغيير رقم يدوي.
- سجل لكل زبون وآخر 100 عملية.
- البحث والتصفية حسب الحساب المفتوح أو المسدود.
- تصدير واسترجاع نسخة JSON.
- واجهة قابلة للتثبيت كـ PWA، وملفات Service Worker للتشغيل بعد أول تحميل.
- قفل اختياري بـ PIN.

## التشغيل
للتجربة المحلية، شغّل خادماً محلياً من داخل المجلد، مثلاً:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000` في المتصفح. الـ PWA وService Worker يحتاجان HTTPS أو localhost. على iPhone، افتح الرابط في Safari ثم Share → Add to Home Screen. على Android، استعمل Install app / Add to Home Screen.

## ملاحظات مهمة قبل الاستعمال الحقيقي
- هذه نسخة MVP تجريبية، وليست جاهزة بعد لإدارة حسابات تجارية حساسة على نطاق واسع.
- البيانات تُحفظ محلياً في المتصفح عبر localStorage. حذف بيانات المتصفح أو ضياع الهاتف قد يسبب فقدانها؛ صدّر نسخة احتياطية بانتظام.
- PIN هو قفل واجهة بسيط وليس تشفيراً لقاعدة البيانات. لا تعتبره حماية قوية ضد شخص لديه وصول تقني إلى الجهاز.
- المزامنة الآمنة بين الأجهزة لم تُنفّذ بعد؛ تحتاج خادماً، حسابات مستخدمين، تشفيراً أثناء النقل، صلاحيات، ونسخاً احتياطية خادمية. لا تضع بيانات الزبناء على خادم قبل إعداد ذلك.
- لا توجد عملية محو/تراجع عن معاملة مفردة في هذه النسخة؛ تأكد من المبالغ قبل التسجيل.
- التطبيق يمنع تسجيل أداء أكبر من الرصيد الحالي، لتجنب رصيد سالب عرضي.

## خطة التطوير التالية
1. إضافة تعديل/إلغاء آمن للعمليات مع سجل تدقيق.
2. إضافة تشفير النسخة الاحتياطية بكلمة مرور.
3. إضافة مزامنة خادمية آمنة بين الأجهزة.
4. اختبار الاستخدام مع مول الحانوت وتحسين الخطوات.
